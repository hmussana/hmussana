### What I like building

- **Guardrails as code.** Preventive controls in IaC, so the audit trail is the pull request.
- **Detection engineering on AWS.** Telemetry first, then rules. Fewer alerts a human has to read.
- **IAM that holds up at scale.** Least privilege that survives the third reorg.
- **IR tooling and forensics.** Python and containers, built for the bad day.
- **Supply-chain security.** Where trust in a build or a vendor quietly breaks.
- **Security vs. cost tradeoffs.** Redesigns that cut spend without cutting coverage.

### Now

- **AI for defensive security.** What earns its keep in detection, triage and IR, and what is a demo.
- **Small-team leverage.** What an LLM changes about what a small security team can own.
